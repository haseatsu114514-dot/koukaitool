# キャラクターと画面の設計

## ビジュアルの軸

落ち着いた夜の紺（`#0b1729`）に、ゴールド（`#e3b45a`）をひとつだけのアクセント色として使う、平らで静かな画面。色は意味のある所だけに使います（ゴールド＝操作・強調、エレメント色＝タイプ）。キャラクターはエレメント色の淡い面（`tint`）に置き、画面でいちばん明るい面にします。

「AIが作ったように見える」定番の飾りは使いません。

- 使わないもの：グラデーションの文字、光る影（グロー）、流れる光沢、回転する光の輪、3Dの傾き、四隅の金マークや「—✦—」のオーナメント、全面のノイズ、星雲・流れ星、動き続ける背景、すりガラス風のカード、英字の飾り見出し（MY STELLA TYPE など）、「01 ——」の番号付き見出し、3つ並びの数字カード、四芒星（✦）。
- ロゴ：ファイル（フォルダ）に五芒星をくり抜いたマーク（`src/lib/logo-path.ts`）。アプリアイコン・favicon・OG画像・共有画像・本の表紙で共通に使う。
- 書体：見出しは明朝（Shippori Mincho B1 700）、本文・小見出し・数字はゴシック（Zen Kaku Gothic New 400/700）。字間は本文0.02〜0.03em、見出し0.04em程度に抑える。
- 面と線：平らな面（`--surface`）と1pxの線（`--line`）。角丸は8px（小）、12px（カード）、16px（パネル）、ボタンとチップは丸。
- 動き：一度きりのフェードインと、結果の「本が開く」演出だけ。`prefers-reduced-motion` ではすべて止める。
- 文字サイズの下限：ラベル11px、補足12px、小さい本文13px。
- 用語：画面では「エレメント」「木・火・土・金・水」を使わず、「緑グループ」のように色で呼ぶ。

文章も同じ考え方で、「〜ではなく〜です」「あなたの〇〇は才能です」「きっと〜」「ぐっと〜」「—（ダッシュ）での署名」のような定型を避け、タイプごとに具体的な行動や場面を書きます。

今回の絵柄版は `stella-soft-bear-v3`。提供されたグリズリー画像を参照し、大きな丸い頭と小さな体、太いこげ茶の輪郭（`#4b281a`）、シンプルな目と眉、暖かなクリーム色と控えめな陰影を共通にしています。表情は性格ごとに変え、ウインク、喜びの目、半目、自信のある笑顔、気遣う顔、照れた顔などを、口と眉・姿勢と組み合わせます。主役が大きく見える正方形の全身イラストを使い、背景の描き込みは抑えます。過去の320×320の仮SVGは削除し、今回の表情付き10体を正式版として使用しています。

キャラクターは小さな一覧でも見分けられるよう、主となる色とシルエットを分けます。動物らしさは耳・口元・模様・シルエットで残し、体色には雪白、バターイエローやラベンダーも使います。五行に対応する緑・赤・黄・白・青のグループ色は画面の背景・枠・表示名で維持し、イラストは固有の体色と小物の色を組み合わせます。

- グリズリー：蜂蜜色の茶色と緑のリボン。
- うさぎ：アイボリーと四つ葉のクローバー。
- フェニックス：コーラルと黄金色のくちばし。
- 妖狐：雪白・パールホワイト（`#ffffff`）の顔、口元、体、外耳、足と大きなしっぽ。陰影は最小限の淡い冷灰色（`#eef1f4`）にし、朱色は耳の内側・隈取り・しっぽの先に小さく添えます。半目の観察眼、片眉を上げた微笑み、頬に前足を添える考える仕草、小さな灯りを保ちます。
- パンダ：アイボリーと黒い模様、黄色の湯のみ。
- アルパカ：はっきりしたバターイエロー（`#f0d784`）の毛、クリーム色の口元。子どもも同じ色の組み合わせ。
- ドーベルマン：シルバーグレーと白・タンの模様、青い首輪。小さな艶消し銀の胸当てと、片方の前足で体の低い位置に持つ丸い銀の盾を添えます。装備は簡単な形に抑え、兜・大きな武器・複雑な甲冑は使いません。
- ハリネズミ：淡いラベンダー（`#b8a6c7`）の針、薄いライラッククリームの顔、青いハート。頭から背中を囲む12〜16本の針は、こげ茶の輪郭と明確に尖った三角形の先端で表現します。体と顔は丸く、照れた表情を保ちます。
- シャチ：紺とクリーム。
- カピバラ：薄い灰茶色・カフェオレ色（`#bca98e`）の体、青緑のお湯。少し縦長の丸い四角形の頭、とても小さな耳、長く突き出た四角い口元、左右に小さな鼻孔を持たせ、少し斜めから描きます。グリズリーよりオレンジ味を抑えた淡い茶色と、口元・頭の形で見分けられるようにします。

## アセットの仕様

`src/data/art-direction.ts` が共通style guideとasset schema、`src/data/types.ts` が固有prompt seedと小道具・背景モチーフを定義。

```ts
type CharacterAsset = {
  slug: string;
  status: 'placeholder' | 'provided' | 'generated' | 'approved';
  src: string;
  displaySrc?: string; // 画面用の同じ寸法の可逆圧縮画像
  alt: string;
  styleVersion: string;
  width: number;
  height: number;
  provenance: { kind: 'original-svg' | 'user-provided' | 'generation'; provider?: string; model?: string; createdAt?: string };
}
```

生成リクエストは `generationRequest(type)` で作ります。共通positive prompt＋固有seed、共通negative prompt、1024×1024、styleVersionを返します。今後生成するときも、保存した参照画像 `docs/character-art/bear-style-reference.png` と合わせて使用します。実行APIや疑似生成はありません。

外部API接続時は、秘密鍵をブラウザへ渡さず、サーバー側のproviderが処理します。生成元・日付・絵柄版を保存し、モデルが分かる場合はモデルも記録します。人の確認後に `approved` とします。アセットは自サイトへ配置するか、画像書き出しに必要なCORSを許可。一時URLを永続アセットURLにしないでください。

## 品質確認

- 主役はキャラクター。小物は1〜2点、背景は疎にする。
- 小さい図鑑カードでも動物と姿勢を読み取れること。
- 隣り合うキャラクターは主となる色を分け、茶色やアイボリーに集中させないこと。
- ハリネズミの針は丸い花びら状にせず、一覧でも尖った先端を読み取れること。
- 毛の描き込み、立体光沢、過剰なハート、大きなアニメ眼、文字の焼き込みを避ける。
- 画像と色、名前、説明文を分離し、文言を画像へ固定しない。
- 結果PNGは1080×1350。日付を渡さない専用処理で書き出す（サイトのWebフォント、ロゴ、サイトURL入り）。
- OG画像は1200×630のJPEG。`pnpm og` で `public/og/` に再生成する。

## アクセシビリティ

フォームは明示ラベルとfieldset/legend、エラーをlive regionで通知。主なボタン46〜56px、focus-visible、本文スキップリンク、reduced-motion、イラストaltを用意。フォントはGoogle Fontsから実行時に読み込み、読み込めない場合はOS標準の日本語フォントで表示します（外部リクエストはプライバシーページで開示）。
